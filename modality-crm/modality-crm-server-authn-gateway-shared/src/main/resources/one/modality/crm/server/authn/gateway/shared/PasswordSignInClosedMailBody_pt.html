Login com senha desativado

Prezado usuário,

Alguém pediu uma forma de entrar na sua conta do Kadampa Bookings sem a senha: um link de login, um código ou a redefinição da senha. Pode ter sido você.

O login com senha está desativado nesta conta, então nada que pudesse abri-la foi enviado. Isso protege a conta enquanto a senha pode ser conhecida.

Para entrar, use sua chave de acesso.

Se você não tem mais o dispositivo onde está sua chave de acesso, responda a este email e ajudaremos você a recuperar o acesso.

Enquanto o login com senha de uma conta está desativado, este aviso é enviado no lugar de um link de login ou de uma redefinição de senha.
