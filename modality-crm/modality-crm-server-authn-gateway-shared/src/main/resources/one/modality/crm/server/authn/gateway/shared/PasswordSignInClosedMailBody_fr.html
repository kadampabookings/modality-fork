Connexion par mot de passe désactivée

Cher utilisateur,

Quelqu’un a demandé un moyen d’accéder à votre compte Kadampa Bookings sans son mot de passe : un lien de connexion, un code ou une réinitialisation du mot de passe. Il s’agit peut-être de vous.

La connexion par mot de passe est désactivée sur ce compte : rien qui puisse l’ouvrir n’a donc été envoyé. Cela protège le compte tant que son mot de passe peut être connu.

Pour vous connecter, utilisez votre clé d’accès.

Si vous n’avez plus l’appareil sur lequel se trouve votre clé d’accès, répondez à cet email et nous vous aiderons à retrouver l’accès.

Tant que la connexion par mot de passe d’un compte est désactivée, cet avis est envoyé à la place d’un lien de connexion ou d’une réinitialisation du mot de passe.
